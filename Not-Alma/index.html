    NOT ALMA VE BİLGİ YÖNETİMİ¶

    Kapsamlı Not Alma Uygulamaları¶

    1. Notion¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (Personal) / Ücretli ($8-15/ay)
    • Özellikler:
    • All-in-one workspace
    • Notes, databases, wikis
    • Templates
    • Collaboration
    • Real-time sync
    • Embed files
    • Integration (Slack, Google, etc.)
    • AI features
    • Block-based editing
    • En İyi Kullanım: All-in-one workspace
    • Web: https://www.notion.so

    2. Evernote¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (sınırlı) / Ücretli ($8-14.99/ay)
    • Özellikler:
    • Note-taking
    • Web clipping
    • Document scanning
    • OCR
    • Search (text + images)
    • Sync
    • Tasks
    • Calendar
    • Home dashboard
    • En İyi Kullanım: Classic note-taking
    • Web: https://evernote.com

    3. Obsidian¶

    • Platform: Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz / Ücretli (Sync & Publish - $4-50/month)
    • Özellikler:
    • Markdown notes
    • Link-based (bi-directional linking)
    • Local-first storage
    • Plugins
    • Graph view
    • Canvas
    • Publish
    • Sync (paid)
    • En İyi Kullanım: Personal Knowledge Base (PKB)
    • Web: https://obsidian.md

    4. Microsoft OneNote¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (Microsoft account ile)
    • Özellikler:
    • Freeform notes
    • Sections & pages
    • Ink/handwriting
    • Search
    • Audio/video notes
    • Tagging
    • Collaboration
    • Microsoft 365 entegrasyonu
    • En İyi Kullanım: Microsoft ekosistemi
    • Web: https://www.onenote.com

    5. Google Keep¶

    • Platform: Web, iOS, Android, Chrome
    • Fiyat: Ücretsiz
    • Özellikler:
    • Simple notes
    • Reminders
    • Color coding
    • Labels
    • Voice memos
    • Image notes
    • Checklists
    • Location-based reminders
    • Google entegrasyonu
    • En İyi Kullanım: Basit ve hızlı notlar
    • Web: https://keep.google.com

    Markdown ve PKB (Personal Knowledge Base)¶

    6. Logseq¶

    • Platform: Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Local-first
    • Markdown & Org-mode
    • Bi-directional linking
    • Graph view
    • Journaling
    • PDF annotation
    • Flashcards
    • En İyi Kullanım: Open-source PKB
    • Web: https://logseq.com

    7. Joplin¶

    • Platform: Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • End-to-end encryption
    • Markdown
    • Web clipper
    • Self-hosted sync
    • Note linking
    • Attachments
    • Plugins
    • En İyi Kullanım: Encrypted, open-source notes
    • Web: https://joplinapp.org

    8. Roam Research¶

    • Platform: Web
    • Fiyat: Ücretli ($15/month)
    • Özellikler:
    • Daily notes
    • Bi-directional linking
    • Block references
    • Graph overview
    • Outliner
    • Templates
    • Database queries
    • PDF viewing
    • En İyi Kullanım: Research ve networked thought
    • Web: https://roamresearch.com

    9. Turtl¶

    • Platform: Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • End-to-end encryption
    • Boards & cards
    • Search
    • Self-hosted
    • Secure
    • En İyi Kullanım: Encrypted note-taking
    • Web: https://turtlapp.com

    10. Trilium Notes¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Hierarchical notes
    • Wiki links
    • Code execution (SQL)
    • Diagramming
    • Calendar
    • Maps
    • Self-hosted
    • En İyi Kullanım: Hierarchical knowledge base
    • Web: https://github.com/zadam/trilium-notes

    Hızlı ve Minimal Not Alma¶

    11. Simplenote¶

    • Platform: Web, Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz
    • Özellikler:
    • Simple
    • Markdown support
    • Sync
    • Version history
    • Collaboration
    • Tags
    • Search
    • Publishing
    • En İyi Kullanım: Minimal, distraction-free notes
    • Web: https://simplenote.com

    12. Apple Notes¶

    • Platform: macOS, iOS
    • Fiyat: Ücretsiz (Apple ekosistemi)
    • Özellikler:
    • Built-in Apple
    • iCloud sync
    • Handwriting/ink
    • Document scanning
    • Checklists
    • Shared notes
    • Tables
    • Tags (iOS 15+)
    • Quick Notes
    • En İyi Kullanım: Apple kullanıcıları
    • Web: https://www.apple.com/macos/notes/

    13. Bear¶

    • Platform: macOS, iOS
    • Fiyat: Ücretsiz (sınırlı) / Ücretli (Pro - $1.49/month)
    • Özellikler:
    • Markdown
    • Beautiful design
    • Organize tags
    • Cross-note links
    • Export (PDF, HTML, etc.)
    • Encryption
    • Focus mode
    • En İyi Kullanım: Mac için Markdown notları
    • Web: https://bear.app

    14. Standard Notes¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz / Ücretli ($2.50-9.99/month)
    • Özellikler:
    • End-to-end encryption
    • Long-term note-taking
    • Markdown
    • Simple editor
    • Sync
    • Offline access
    • Extended editors (paid)
    • En İyi Kullanım: Secure notes
    • Web: https://standardnotes.com

    15. QOwnNotes¶

    • Platform: Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Markdown
    • Nextcloud sync
    • OwnCloud sync
    • Scripting
    • WebDAV support
    • Encryption
    • En İyi Kullanım: Nextcloud integration
    • Web: https://www.qownnotes.org

    • Özellikler:

    • Team spaces

    • Comments & inline discussions
    • En İyi Kullanım: Team knowledge management
    • Web: https://www.atlassian.com/software/confluence

    17. Slite¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (8 doküman) / Ücretli ($8/month)
    • Özellikler:
    • Team knowledge base
    • Collaboration
    • Real-time editing
    • Integrations
    • Comments & discussions
    • Docs
    • Channels
    • Onboarding
    • En İyi Kullanım: Modern team documentation
    • Web: https://slite.com

    18. Coda¶

    • Platform: Web, iOS, Android
    • Fiyat: Ücretsiz (docs unlimited) / Ücretli (Pro - $10/month)
    • Özellikler:
    • Docs + spreadsheets
    • Buttons & automations
    • Integration packs
    • Collaboration
    • Templates
    • Packs (extensions)
    • Building blocks
    • En İyi Kullanım: Interactive documents
    • Web: https://coda.io

    19. Workflowy¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (sınırlı) / Ücretli ($4.99/month)
    • Özellikler:
    • Infinite list
    • Outline-based
    • Zoom in/out
    • Backlinks
    • Search
    • Board view
    • Daily notes
    • En İyi Kullanım: Organized lists & outlines

    • Dark mode
    • Image upload
    • En İyi Kullanım: Outliner-style notes
    • Web: https://dynalist.io
