    BULUT BİLİŞİM VE DEVOPS¶

    Bulut Hizmet Sağlayıcıları¶

    1. Amazon Web Services (AWS)¶

    • Platform: Web
    • Fiyat: Pay-as-you-go (Ücretsiz katman mevcut)
    • Özellikler:
    • Geniş hizmet yelpazesi
    • Compute (EC2, Lambda)
    • Storage (S3, EBS)
    • Database (RDS, DynamoDB)
    • Networking (VPC, CloudFront)
    • Machine Learning (SageMaker, Rekognition)
    • Security (IAM, Shield)
    • DevOps (CodePipeline, CodeDeploy)
    • Serverless (Lambda, Fargate)
    • Enterprise support
    • En İyi Kullanım: Kapsamlı bulut çözümleri ve enterprise uygulamalar
    • Web: https://aws.amazon.com

    2. Microsoft Azure¶

    • Platform: Web
    • Fiyat: Pay-as-you-go (Ücretsiz katman mevcut)
    • Özellikler:
    • Windows ve Linux uyumlu
    • Compute (VMs, Functions)
    • Storage (Blob, Disk)
    • Database (SQL, Cosmos DB)
    • Networking (VNet, CDN)
    • AI (Cognitive Services, Machine Learning)
    • DevOps (DevOps, GitHub Actions)
    • Hybrid cloud (Azure Stack)
    • Enterprise integration
    • Microsoft ecosystem
    • En İyi Kullanım: Microsoft tabanlı uygulamalar ve enterprise
    • Web: https://azure.microsoft.com

    3. Google Cloud Platform (GCP)¶

    • Platform: Web
    • Fiyat: Pay-as-you-go (Ücretsiz katman mevcut)
    • Özellikler:
    • Machine learning odaklı
    • Compute (Compute Engine, Cloud Run)
    • Storage (Cloud Storage, BigQuery)
    • Database (Cloud SQL, Firestore)
    • AI/ML (Vertex AI, AutoML)
    • Kubernetes (GKE, Anthos)
    • Serverless (Cloud Functions)
    • Big data (BigQuery, Dataflow)
    • Analytics (Looker, Data Studio)
    • Developer tools
    • En İyi Kullanım: AI/ML ve veri analizi uygulamaları
    • Web: https://cloud.google.com

    4. Alibaba Cloud¶

    • Platform: Web
    • Fiyat: Pay-as-you-go (Ücretsiz katman mevcut)
    • Özellikler:
    • Asya pazarı odaklı
    • Compute (ECS, Function Compute)
    • Storage (OSS, NAS)
    • Database (RDS, PolarDB)
    • AI/ML (PAI, Machine Learning)
    • Networking (VPC, CDN)
    • Security (WAF, DDoS Protection)
    • Big data (MaxCompute, Data Lake)
    • Database services
    • Enterprise solutions
    • En İyi Kullanım: Asya pazarı ve enterprise uygulamalar
    • Web: https://www.alibabacloud.com

    5. IBM Cloud¶

    • Platform: Web
    • Fiyat: Pay-as-you-go (Ücretsiz katman mevcut)
    • Özellikler:
    • Enterprise odaklı
    • Hybrid cloud
    • AI/ML (Watson, ML)
    • Compute (Virtual Servers, Functions)
    • Storage (Object Storage, Block Storage)
    • Database (DB2, Cloudant)
    • Kubernetes (OpenShift, Kubernetes Service)
    • DevOps (DevOps, Continuous Delivery)
    • Security (Security Center, Identity)
    • Enterprise integration
    • En İyi Kullanım: Kurumsal uygulamalar ve hibrit bulut
    • Web: https://www.ibm.com/cloud

    Konteyner ve Orkestrasyon¶

    6. Docker¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz / Ücretli (Personal, Pro, Team)
    • Özellikler:
    • Containerization platform
    • Image management
    • Container orchestration
    • Docker Compose
    • Docker Swarm
    • Docker Hub
    • Container security
    • Developer tools
    • Integration tools
    • Community support
    • En İyi Kullanım: Uygulama konteynerleştirme ve dağıtım
    • Web: https://www.docker.com

    7. Kubernetes¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
