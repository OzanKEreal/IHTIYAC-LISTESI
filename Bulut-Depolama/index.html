    BULUT DEPOLAMA VE SİNKRONİZASYON¶

    Popüler Bulut Depolama Hizmetleri¶

    1. Google Drive¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (15GB) / Ücretli ($1.99-299.99/ay)
    • Özellikler:
    • Google ekosistemi entegrasyonu
    • Real-time collaboration
    • File sharing
    • Version history
    • Offline access
    • AI-powered search
    • Google Docs integration
    • Mobile backup
    • Scan to PDF
    • En İyi Kullanım: Google kullanıcıları ve collaboration
    • Web: https://www.google.com/drive

    2. Microsoft OneDrive¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (5GB) / Ücretli ($1.99-12.50/ay)
    • Özellikler:
    • Windows entegrasyonu
    • Microsoft 365 ile çalışır
    • Personal vault
    • File sharing
    • Version history
    • Ransomware detection
    • Files On-Demand
    • Camera upload
    • Backup (PC, Mac, Phone)
    • En İyi Kullanım: Windows ve Microsoft 365
    • Web: https://www.microsoft.com/onedrive

    3. Dropbox¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (2GB) / Ücretli ($9.99-30/ay)
    • Özellikler:
    • Simple interface
    • File sharing
    • Smart Sync
    • Version history
    • File requests
    • Transfer (up to 100GB)
    • Password protect links
    • Remote device wipe
    • Backup (PC, Mac)
    • En İyi Kullanım: Kolay dosya paylaşımı
    • Web: https://www.dropbox.com

    4. Apple iCloud¶

    • Platform: macOS, iOS, Windows, Web
    • Fiyat: Ücretsiz (5GB) / Ücretli ($0.99-29.95/ay)
    • Özellikler:
    • Apple ekosistemi
    • Photos sync
    • Device backup
    • Find My iPhone
    • Keychain (passwords)
    • iCloud Drive
    • iCloud Photos
    • Collaboration
    • Private Relay (VPN)
    • En İyi Kullanım: Apple kullanıcıları
    • Web: https://www.icloud.com

    5. Box¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (10GB) / Ücretli ($5-35/ay)
    • Özellikler:
    • Enterprise-focused
    • Advanced security
    • File sharing
    • Collaboration
    • Workflow automation
    • Sign (e-signature)
    • Integration (Microsoft, Google, Slack)
    • Governance & compliance
    • Retention policies
    • En İyi Kullanım: İş ve enterprise
    • Web: https://www.box.com

    Özelleştirilebilir Bulut Depolama¶

    6. pCloud¶

    • Platform: Web, Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz (10GB) / Ücretli ($3.99-7.99/ay)
    • Özellikler:
    • Lifetime subscription
    • Client-side encryption
    • File sharing
    • Rewind (file versions)
    • Media player
    • Extension support
    • Virtual drive
    • Crypto folder
    • En İyi Kullanım: Lifetime subscription ve encryption
    • Web: https://www.pcloud.com

    7. Sync.com¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (5GB) / Ücretli ($8-15/ay)
    • Özellikler:
    • Zero-knowledge encryption
    • Canada-based
    • File sharing
    • Secure vault
    • File requests
    • Calendar integration
    • Team folders
    • Mobile apps
    • En İyi Kullanım: Privacy odaklı storage
    • Web: https://www.sync.com

    8. Icedrive¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (10GB) / Ücretli ($2.99-14.99/ay)
    • Özellikler:
    • Twofish encryption
    • Virtual drive
    • Mount as drive
    • File sharing
    • Zero-knowledge
    • Auto-upload
    • Files versioning
    • Password protect
    • En İyi Kullanım: Privacy ve virtual drive
    • Web: https://icedrive.net

    9. MEGA¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (20GB) / Ücretli ($4.90-22.49/ay)
    • Özellikler:
    • End-to-end encryption
    • Large storage
    • File sharing
    • Chat encrypted
    • Secure transfer
    • File requests
    • Backup
    • Camera upload
    • En İyi Kullanım: Büyük dosya depolama
    • Web: https://mega.io

    10. Tresorit¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz deneme / Ücretli ($8.33-24/ay)
    • Özellikler:
    • End-to-end encryption
    • Advanced security
    • File sharing
    • Access controls
    • Swiss-based
    • GDPR compliant
    • Integration (Microsoft, Google)
    • Governance
    • En İyi Kullanım: Enterprise güvenlik
    • Web: https://tresorit.com

    Self-Hosted ve Private Cloud¶

    11. Nextcloud¶

    • Platform: Linux server (clients: Windows, macOS, iOS, Android)
    • Fiyat: Ücretsiz (self-hosted) / Ücretli (enterprise)
    • Özellikler:
    • Self-hosted
    • Open source
    • File sharing
    • Collaboration (Office, Calendar, Contacts)
    • Encryption
    • 2FA
    • App ecosystem
    • Integration
    • Custom domain
    • En İyi Kullanım: Self-hosted private cloud
    • Web: https://nextcloud.com

    12. ownCloud¶

    • Platform: Linux server (clients: Windows, macOS, iOS, Android)
    • Fiyat: Ücretsiz (community) / Ücretli (enterprise)
    • Özellikler:
    • Open source
    • Self-hosted
    • File sharing
    • Enterprise features
    • Workflow automation
    • Data privacy
    • Security features
    • Integration
    • En İyi Kullanım: Self-hosted enterprise
    • Web: https://owncloud.com

    13. Seafile¶

    • Platform: Linux server (clients: Windows, macOS, iOS, Android)
    • Fiyat: Ücretsiz (community) / Ücretli (Pro - $120-300/yıl)
    • Özellikler:
    • High performance
    • Open source
    • Self-hosted
    • File encryption
    • File versioning
    • Synchronization
    • WORM (write-once-read-many)
    • Team features
    • En İyi Kullanım: High-performance self-hosted
    • Web: https://www.seafile.com

    14. Synology Drive¶

    • Platform: Synology NAS (clients: Windows, macOS, iOS, Android)
    • Fiyat: Ücretsiz (Synology NAS ile birlikte)
    • Özellikler:
    • NAS entegrasyonu
    • File sync
    • Version history
    • File sharing
    • On-demand sync
    • Offline access
    • Backup
    • Collaboration
    • En İyi Kullanım: Synology NAS kullanıcıları
    • Web: https://www.synology.com

    15. Pydio Cells¶

    • Platform: Linux server (clients: Windows, macOS, iOS, Android)
    • Fiyat: Ücretsiz (community) / Ücretli (enterprise)
    • Özellikler:
    • Open source
    • Self-hosted
    • Enterprise-focused
    • Advanced security
    • Governance
    • Integration
    • File sharing
    • Collaboration
    • En İyi Kullanım: Enterprise self-hosted
    • Web: https://pydio.com

    Media ve Fotoğraf Odaklı Bulut Depolama¶

    16. Flickr¶

    • Platform: Web, iOS, Android
    • Fiyat: Ücretsiz (1000 fotoğraf) / Ücretli ($7.99-10.99/ay)
    • Özellikler:
    • Photo sharing
    • Community
    • Organize albums
    • Advanced photo editing
    • Groups
    • Explore
    • Statistics
    • En İyi Kullanım: Fotoğrafçılık community
    • Web: https://www.flickr.com

    17. SmugMug¶

    • Platform: Web, iOS, Android
    • Fiyat: Ücretli ($9-42/ay)
    • Özellikler:
    • Photo storage
    • Portfolio sites
    • E-commerce (sell photos)
    • Unlimited storage
    • Full-resolution backup
    • Printing
    • Digital downloads
    • En İyi Kullanım: Profesyonel fotoğrafçılar
    • Web: https://www.smugmug.com

    18. Amazon Photos¶

    • Platform: Web, iOS, Android, Fire devices
    • Fiyat: Ücretsiz (unlimited photos for Prime members)
    • Özellikler:
    • Unlimited photo storage
    • 5GB video storage (Prime)
    • Auto backup
    • Family vault
    • Search
    • Print (US only)
    • Shared albums
    • En İyi Kullanım: Amazon Prime üyeleri
    • Web: https://www.amazon.com/photos

    19. Google Photos¶

    • Platform: Web, iOS, Android
    • Fiyat: Ücretsiz (15GB shared) / Ücretli ($1.99-9.99/ay)
    • Özellikler:
    • Photo backup
    • AI-powered features
    • Memory (öneriler)
    • Photo editing
    • Shared albums
    • Motion photos
    • Cinematic photos
    • Portrait light
    • En İyi Kullanım: AI-powered fotoğraf yönetimi
    • Web: https://photos.google.com

    20. Apple Photos (iCloud Photos)¶

    • Platform: macOS, iOS, Windows, Web
    • Fiyat: Ücretsiz (5GB shared) / Ücretli ($0.99-29.95/ay)
    • Özellikler:
    • Apple ekosistemi
    • Intelligent curation
    • Memories
    • For You
    • Shared albums
    • Live Photos
    • Photo editing
    • iCloud sync
    • En İyi Kullanım: Apple fotoğraf yönetimi
    • Web: https://www.icloud.com/photos
