    SANAL MAKİNE VE VIRTUALİZASYON¶

    Desktop Virtualization¶

    1. VMware Workstation Pro¶

    • Platform: Windows, Linux
    • Fiyat: Ücretsiz (Player) / Ücretli (Workstation Pro - $199)
    • Özellikler:
    • Desktop virtualization
    • Run multiple OS
    • Snapshots
    • Cloning
    • Shared folders
    • Unity mode
    • 3D graphics support
    • Network modes (NAT, Bridged, etc.)
    • En İyi Kullanım: Professional desktop virtualization
    • Web: https://www.vmware.com/products/workstation-pro.html

    2. VMware Fusion¶

    • Platform: macOS
    • Fiyat: Ücretli ($149 for new)
    • Özellikler:
    • Mac için virtualization
    • Windows, Linux, macOS guests
    • Unity mode
    • Snapshots
    • Cloning
    • Graphics acceleration
    • Shared folders
    • En İyi Kullanım: Mac virtualization
    • Web: https://www.vmware.com/products/fusion.html

    3. Oracle VirtualBox¶

    • Platform: Windows, macOS, Linux, Solaris
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Cross-platform
    • Multiple OS support
    • Snapshots
    • Shared folders
    • VirtualBox Guest Additions
    • Headless mode
    • Virtual networking
    • En İyi Kullanım: Free desktop virtualization
    • Web: https://www.virtualbox.org

    4. Parallels Desktop¶

    • Platform: macOS
    • Fiyat: Ücretli ($99.99/year)
    • Özellikler:
    • Mac için optimize
    • Windows, Linux, Android guests
    • Coherence mode
    • Performance optimize
    • Metal graphics
    • Shared folders
    • Apple Silicon support
    • Seamless integration
    • En İyi Kullanım: Mac için premium virtualization
    • Web: https://www.parallels.com/products/desktop

    5. QEMU (Quick Emulator)¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Emulation
    • Virtualization
    • KVM integration (Linux)
    • Multiple guest OS
    • Disk images
    • Network modes
    • Snapshots (qemu-img)
    • En İyi Kullanım: Open-source virtualization
    • Web: https://www.qemu.org

    Containerization¶

    6. Docker Desktop¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz (Personal) / Ücretli (Pro, Team, Business)
    • Özellikler:
    • Containerization
    • Docker Engine
    • Docker Compose
    • Kubernetes
    • Docker Hub
    • GUI
    • Extensions
    • WSL2 integration (Windows)
    • En İyi Kullanım: Container development
    • Web: https://www.docker.com/products/docker-desktop

    7. Podman¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Daemonless
    • Compatible with Docker
    • Rootless containers
    • Pod management
    • Kubernetes integration (Podman Desktop)
    • Security features
    • En İyi Kullanım: Docker alternative
    • Web: https://podman.io

    8. Kubernetes (k3s, minikube)¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Container orchestration
    • k3s (lightweight)
    • minikube (local cluster)
    • Docker alternative
    • Microservices
    • Scalability
    • En İyi Kullanım: Container orchestration
    • Web: https://kubernetes.io

    Windows Built-in Virtualization¶

    9. Hyper-V¶

    • Platform: Windows (Pro, Enterprise, Education)
    • Fiyat: Ücretsiz (Windows ile birlikte)
    • Özellikler:
    • Windows built-in
    • Virtual machines
    • Virtual switches
    • Virtual disks
    • Checkpoints (snapshots)
    • Live migration (Server)
    • Enhanced session mode
    • En İyi Kullanım: Windows virtualization
    • Web: https://docs.microsoft.com/windows-server/virtualization/hyper-v

    10. Windows Sandbox¶

    • Platform: Windows (Pro, Enterprise)
    • Fiyat: Ücretsiz (Windows ile birlikte)
    • Özellikler:
    • Temporary virtual environment
    • Secure
    • Clean desktop
    • No persistent files
    • Integrated with Windows
    • En İyi Kullanım: Safe application testing
    • Web: https://docs.microsoft.com/windows/security/threat-protection/windows-sandbox

    11. Windows Subsystem for Linux (WSL)¶

    • Platform: Windows
    • Fiyat: Ücretsiz
    • Özellikler:
    • Linux kernel
    • Run Linux natively
    • WSL 2 (real kernel)
    • Integration with Windows
    • VS Code Remote
    • Docker support
    • En İyi Kullanım: Linux on Windows
    • Web: https://docs.microsoft.com/windows/wsl

    Remote Desktop ve VNC¶

    12. AnyDesk¶

    • Platform: Windows, macOS, Linux, iOS, Android
    • Fiyat: Ücretsiz (personal) / Ücretli ($10-60/month)
    • Özellikler:
    • Remote desktop
    • Low latency
    • File transfer
    • Session recording
    • Security
    • Unattended access
    • Custom client
    • Mobile apps
    • En İyi Kullanım: Remote desktop
    • Web: https://anydesk.com

    13. TeamViewer¶

    • Platform: Windows, macOS, Linux, iOS, Android
    • Fiyat: Ücretsiz (personal) / Ücretli ($49.90-110.90/month)
    • Özellikler:
    • Remote desktop
    • File transfer
    • Wake-on-LAN
    • Meeting functionality
    • Security
    • Custom modules
    • Mobile apps
    • En İyi Kullanım: Popular remote desktop
    • Web: https://www.teamviewer.com

    14. RealVNC Connect¶

    • Platform: Windows, macOS, Linux, iOS, Android
    • Fiyat: Ücretsiz (Home) / Ücretli ($3.39-44.39/month)
    • Özellikler:
    • VNC protocol
    • Remote desktop
    • File transfer
    • Chat
    • Printing
    • Cloud connectivity
    • Security
    • En İyi Kullanım: VNC remote access
    • Web: https://www.realvnc.com

    15. Apache Guacamole¶

    • Platform: Web (server runs on Linux)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Web-based remote desktop
    • VNC, RDP, SSH support
    • No client installation
    • Multi-user
    • Session recording
    • File transfer
    • En İyi Kullanım: Web-based remote desktop
    • Web: https://guacamole.apache.org

    Specialized Virtualization Tools¶

    16. VMware ESXi¶

    • Platform: Physical server
    • Fiyat: Ücretsiz (Hypervisor) / Ücretli (vCenter Server)
    • Özellikler:
    • Type-1 hypervisor
    • Enterprise virtualization
    • Direct hardware access
    • vSphere integration
    • High availability
    • vMotion
    • Distributed Resource Scheduler (DRS)
    • En İyi Kullanım: Enterprise hypervisor
    • Web: https://www.vmware.com/products/esxi-and-esx.html

    17. Proxmox VE¶

    • Platform: Linux (Debian-based)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Type-1 hypervisor
    • KVM + LXC containers
    • Web interface
    • Cluster support
    • Backup & restore
    • High availability
    • ZFS support
    • En İyi Kullanım: Open-source hypervisor
    • Web: https://www.proxmox.com

    18. Xen Project¶

    • Platform: Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Type-1 hypervisor
    • Paravirtualization, HVM
    • High performance
    • XenServer commercial support
    • Cloud platforms (XCP-ng)
    • En İyi Kullanım: Open-source hypervisor
    • Web: https://xenproject.org

    19. Vagrant¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Virtual machine management
    • Vagrantfile (IaC)
    • Provisioning (Puppet, Chef, etc.)
    • Cross-platform
    • Reproducible environments
    • Works with VirtualBox, VMware, Hyper-V, etc.
    • En İyi Kullanım: Reproducible dev environments
    • Web: https://www.vagrantup.com

    20. KVM (Kernel-based Virtual Machine)¶

    • Platform: Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Type-1 hypervisor
    • Linux kernel
    • Hardware acceleration
    • High performance
    • Live migration
    • Management tools (virt-manager, virsh)
    • En İyi Kullanım: Linux virtualization
    • Web: https://www.linux-kvm.org
