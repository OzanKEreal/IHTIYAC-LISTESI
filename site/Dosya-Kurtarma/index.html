    DOSYA KURTARMA VE VERİ GÜVENLİĞİ¶

    Veri Kurtarma Yazılımları¶

    1. Recuva¶

    • Platform: Windows
    • Fiyat: Ücretsiz / Ücretli (Professional - $19.95)
    • Özellikler:
    • Deleted files recovery
    • Deep scan
    • Quick scan
    • Partition recovery
    • Drive scan
    • Secure delete
    • Format recovery
    • Recycle bin recovery
    • Camera card recovery
    • En İyi Kullanım: Windows için popüler veri kurtarma
    • Web: https://www.ccleaner.com/recuva

    2. Disk Drill¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz (Basic) / Ücretli (Pro - $89)
    • Özellikler:
    • Quick scan & deep scan
    • Partition recovery
    • Raw scan
    • All file types
    • Pause & resume
    • Preview before recovery
    • Data protection (Pro)
    • RAID recovery (Pro)
    • En İyi Kullanım: Kapsamlı veri kurtarma
    • Web: https://www.cleverfiles.com/data-recovery-software.html

    3. EaseUS Data Recovery Wizard¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz (2GB) / Ücretli ($69.95-199.95)
    • Özellikler:
    • All types of files
    • Deleted/formatted recovery
    • Partition recovery
    • RAW recovery
    • Quick & deep scan
    • Preview
    • Resume recovery
    • Bootable media (Pro)
    • En İyi Kullanım: Profesyonel veri kurtarma
    • Web: https://www.easeus.com/data-recovery-wizard

    4. Stellar Data Recovery¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz (1GB) / Ücretli ($49.99-299)
    • Özellikler:
    • Quick scan & deep scan
    • Deleted/formatted recovery
    • Partition recovery
    • Raw recovery
    • Photo/video recovery
    • Email recovery (Pro)
    • Preview
    • Bootable drive (Pro)
    • En İyi Kullanım: Profesyonel veri kurtarma
    • Web: https://www.stellarinfo.com

    5. TestDisk¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Recover lost partitions
    • Bootable disk recovery
    • Non-booting system recovery
    • Partition table repair
    • Rebuild partition tables
    • Fix FAT, NTFS, ext2/3/4, etc.
    • PhotoRec companion
    • En İyi Kullanım: Partition kurtarma ve repair
    • Web: https://www.cgsecurity.org/wiki/TestDisk

    Mac Özel Veri Kurtarma¶

    6. Disk Drill (Mac)¶

    • Platform: macOS
    • Fiyat: Ücretsiz (Basic) / Ücretli (Pro - $89)
    • Özellikler:
    • Mac optimize
    • Quick & deep scan
    • Partition recovery
    • Raw scan
    • Time Machine backup recovery
    • APFS, HFS+, FAT, exFAT, NTFS
    • Preview
    • Data protection
    • En İyi Kullanım: Mac için kapsamlı kurtarma
    • Web: https://www.cleverfiles.com/data-recovery-mac

    7. Data Rescue¶

    • Platform: macOS, Windows
    • Fiyat: Ücretsiz (deneme) / Ücretli ($99-399)
    • Özellikler:
    • Advanced recovery
    • Quick & deep scan
    • Partition recovery
    • Raw scan
    • File preview
    • Cloning
    • Bootable drive (Pro)
    • RAID recovery (Pro)
    • En İyi Kullanım: Mac için profesyonel kurtarma
    • Web: https://www.prosofteng.com/data-rescue

    8. DiskWarrior¶

    • Platform: macOS
    • Fiyat: Ücretli ($119.99)
    • Özellikler:
    • Directory repair
    • Optimized directory
    • Recover data from damaged drives
    • HFS+, APFS
    • Prevent drive failure
    • Fix problems
    • Bootable disk
    • En İyi Kullanım: Mac directory repair
    • Web: https://www.alsoft.com/DiskWarrior

    9. R-Studio¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz (recovery limit 256KB) / Ücretli ($79.99-499.99)
    • Özellikler:
    • Advanced recovery
    • Partition recovery
    • Raw file search
    • RAID recovery
    • Network recovery
    • Supported: NTFS, FAT, exFAT, HFS+, APFS, UFS, ReFS, etc.
    • Preview
    • En İyi Kullanım: Profesyonel veri kurtarma
    • Web: https://www.r-studio.com

    10. PhotoRec¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Recover photos, videos, documents
    • Works even if file system damaged
    • Supports: FAT, NTFS, exFAT, HFS+, APFS, ext2/3/4, etc.
    • Deep scan
    • No preview
    • Command line
    • En İyi Kullanım: Open-source veri kurtarma
    • Web: https://www.cgsecurity.org/wiki/PhotoRec

    • Web: https://foremost.sourceforge.net

    12. Scalpel¶

    • Platform: Linux, macOS
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:

    • High performance
    • Memory efficient
    • Command line
    • En İyi Kullanım: Linux data carving
    • Web: https://github.com/sleuthkit/scalpel

    13. ddrescue¶

    • Copies data
    • Error handling
    • Resume capability
    • Command line
    • En İyi Kullanım: Failing drive kurtarma
    • Web: https://www.gnu.org/software/ddrescue

    • Platform: Linux

    • Multiple passes
    • Verbose output
    • Command line
    • En İyi Kullanım: Damaged media kurtarma
    • Web: http://safecopy.sourceforge.net

    • Platform: Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Partition recovery
