    PROJE YÖNETİMİ VE İŞ AKIŞI¶

    Kapsamlı Proje Yönetimi Platformları¶

    1. Asana¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (Basic) / Ücretli ($10.99-24.99/ay)
    • Özellikler:
    • Task management
    • Projects
    • Timelines (Gantt)
    • Forms
    • Portfolios
    • Goals
    • Dashboards
    • Automation
    • Integration (Slack, Google, etc.)
    • Custom fields
    • En İyi Kullanım: Team project management
    • Web: https://asana.com

    2. Trello¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz / Ücretli ($5-17.50/ay)
    • Özellikler:
    • Kanban boards
    • Cards & checklists
    • Power-Ups (extensions)
    • Automation (Butler)
    • Templates
    • Team collaboration
    • Due dates & reminders
    • Attachments
    • En İyi Kullanım: Kanban boards
    • Web: https://trello.com

    3. Monday.com¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (2 kullanıcı) / Ücretli ($8-24/ay)
    • Özellikler:
    • Work OS
    • Project tracking
    • Automations
    • Integrations
    • Views (Table, Kanban, Timeline, Gantt)
    • Forms
    • Dashboards
    • CRM
    • Collaboration
    • En İyi Kullanım: Visual project management
    • Web: https://monday.com

    4. Notion¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (Personal) / Ücretli ($8-15/ay)
    • Özellikler:
    • All-in-one workspace
    • Tasks, databases, wikis
    • Templates
    • Kanban views
    • Calendar views
    • Timeline views
    • Collaboration
    • Integrations
    • En İyi Kullanım: Flexible project management
    • Web: https://www.notion.so

    5. ClickUp¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (unlimited tasks) / Ücretli ($7-19/ay)
    • Özellikler:
    • All-in-one productivity
    • Tasks, docs, goals
    • Multiple views (List, Board, Gantt)
    • Automations
    • Time tracking
    • Mind maps
    • Whiteboards
    • Dashboards
    • En İyi Kullanım: Comprehensive productivity platform
    • Web: https://clickup.com

    Agile ve Software Development¶

    6. Jira¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (10 kullanıcı) / Ücretli ($7.50-14.50/ay)
    • Özellikler:
    • Agile & Scrum boards
    • Sprint planning
    • Issue tracking
    • Roadmaps
    • Integrations (Bitbucket, GitHub)
    • Automation
    • Reports & insights
    • Custom workflows
    • En İyi Kullanım: Software development & agile
    • Web: https://www.atlassian.com/software/jira

    7. Linear¶

    • Platform: Web, macOS, iOS
    • Fiyat: Ücretsiz (10 issues) / Ücretli ($8-16/ay)
    • Özellikler:
    • Modern UI
    • Issue tracking
    • Roadmaps
    • Cycles (sprints)
    • Integrations (GitHub, Slack)
    • Command palette
    • Keyboard shortcuts
    • Real-time sync
    • En İyi Kullanım: Modern software teams
    • Web: https://linear.app

    8. Shortcut (daha önce Clubhouse)¶

    • Platform: Web, macOS, iOS, Chrome
    • Fiyat: Ücretsiz (10 kullanıcı) / Ücretli ($8-14/ay)
    • Özellikler:
    • Agile project management
    • Kanban boards
    • Story mapping
    • Iterations
    • Docs integration
    • GitHub, GitLab, Slack integration
    • Insights & analytics
    • En İyi Kullanım: Software development teams
    • Web: https://shortcut.com

    9. Azure DevOps¶

    • Platform: Web
    • Fiyat: Ücretsiz (5 users) / Ücretli ($6-30/ay)
    • Özellikler:
    • Azure boards (project tracking)
    • Azure repos (Git)
    • Azure pipelines (CI/CD)
    • Test plans
    • Artifacts
    • Microsoft entegrasyonu
    • Scrum & Kanban
    • En İyi Kullanım: Microsoft DevOps ekosistemi
    • Web: https://azure.microsoft.com/devops

    10. GitHub Projects¶

    • Platform: Web
    • Fiyat: Ücretsiz (public repositories) / Ücretli (private repositories)
    • Özellikler:
    • GitHub entegrasyonu
    • Kanban boards
    • Tables
    • Automations
    • Issue tracking
    • Pull request linking
    • Milestones
    • Labels
    • En İyi Kullanım: GitHub tabanlı proje yönetimi
    • Web: https://docs.github.com/issues/planning-and-tracking-with-projects

    • Web: https://todoist.com

    • Fiyat: Ücretsiz
    • Özellikler:

    • En İyi Kullanım: Microsoft task management
