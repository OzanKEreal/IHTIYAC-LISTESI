    VERİ BİLİMİ VE MAKİNE ÖĞRENMESİ¶

    Python Framework'ler ve Kütüphaneler¶

    1. NumPy¶

    • Platform: Python
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Array manipulation
    • Numerical computing
    • Broadcasting
    • Linear algebra
    • FFT (Fast Fourier Transform)
    • Random number generation
    • C-optimized
    • En İyi Kullanım: Numerical computing
    • Web: https://numpy.org

    2. pandas¶

    • Platform: Python
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Data analysis
    • Data structures (DataFrame, Series)
    • Data cleaning
    • Data manipulation
    • Time series
    • Integration (NumPy, matplotlib, etc.)
    • Excel/CSV import/export
    • En İyi Kullanım: Data manipulation ve analysis
    • Web: https://pandas.pydata.org

    3. scikit-learn¶

    • Platform: Python
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Machine learning
    • Supervised learning (classification, regression)
    • Unsupervised learning (clustering, dimensionality reduction)
    • Model selection
    • Preprocessing
    • Pipeline
    • Feature extraction
    • En İyi Kullanım: Traditional ML
    • Web: https://scikit-learn.org

    4. TensorFlow¶

    • Platform: Python, C++, JavaScript
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Deep learning
    • Neural networks
    • TFLite (mobile deployment)
    • TensorFlow Serving
    • Keras API
    • Distributed training
    • TPU/GPU support
    • En İyi Kullanım: Deep learning framework
    • Web: https://www.tensorflow.org

    5. PyTorch¶

    • Platform: Python
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Deep learning
    • Dynamic computation graph
    • GPU acceleration (CUDA)
    • Distributed training
    • TorchScript
    • ONNX support
    • Research-friendly
    • En İyi Kullanım: Deep learning research
    • Web: https://pytorch.org

    • Script editor
    • Plotting
    • Package management
    • Git integration
    • R Markdown

    • En İyi Kullanım: R development
    • Web: https://www.rstudio.com

    7. tidyverse¶

    • Platform: R
    • Fiyat: Ücretsiz ve Açık Kaynak

    8. caret¶

    • Platform: R
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Unified ML interface
    • Model training
    • Preprocessing
    • Feature selection
    • Model tuning
    • Cross-validation
    • 200+ ML algorithms
    • En İyi Kullanım: R machine learning
    • Web: https://topepo.github.io/caret

    9. Shiny¶

    • Platform: R
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:

    • Interactive dashboards
    • Reactivity
    • UI customization
    • R Markdown
    • Shiny Server
    • En İyi Kullanım: Interactive R dashboards
    • Web: https://shiny.rstudio.com

    10. R Markdown¶

    • Platform: R
    • Fiyat: Ücretsiz ve Açık Kaynak

    • Web: https://rmarkdown.rstudio.com
