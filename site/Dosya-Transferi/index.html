    DOSYA TRANSFERİ VE SENKRONİZASYON¶

    Cloud ve Sync Araçları¶

    1. Dropbox¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (2GB) / Ücretli ($9.99-30/ay)
    • Özellikers:
    • Cloud sync
    • File sharing
    • Smart Sync
    • Version history
    • File requests
    • Transfer (up to 100GB)
    • Password protect links
    • Remote device wipe
    • Backup (PC, Mac)
    • En İyi Kullanım: Kolay dosya paylaşımı
    • Web: https://www.dropbox.com

    2. Google Drive¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (15GB) / Ücretli ($1.99-299.99/ay)
    • Özellikers:
    • Google ekosistemi entegrasyonu
    • Real-time collaboration
    • File sharing
    • Version history
    • Offline access
    • AI-powered search
    • Google Docs integration
    • Mobile backup
    • Scan to PDF
    • En İyi Kullanım: Google kullanıcıları
    • Web: https://www.google.com/drive

    3. OneDrive¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (5GB) / Ücretli ($1.99-12.50/ay)
    • Özellikers:
    • Windows entegrasyonu
    • Microsoft 365 ile çalışır
    • Personal vault
    • File sharing
    • Version history
    • Ransomware detection
    • Files On-Demand
    • Camera upload
    • Backup (PC, Mac, Phone)
    • En İyi Kullanım: Windows ve Microsoft 365
    • Web: https://www.microsoft.com/onedrive

    4. iCloud Drive¶

    • Platform: macOS, iOS, Windows, Web
    • Fiyat: Ücretsiz (5GB) / Ücretli ($0.99-29.95/ay)
    • Özellikers:
    • Apple ekosistemi
    • Photos sync
    • Device backup
    • Find My iPhone
    • Keychain (passwords)
    • iCloud Drive
    • iCloud Photos
    • Collaboration
    • Private Relay (VPN)
    • En İyi Kullanım: Apple kullanıcıları
    • Web: https://www.icloud.com

    5. MEGA¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (20GB) / Ücretli ($4.90-22.49/ay)
    • Özellikers:
    • End-to-end encryption
    • Large storage
    • File sharing
    • Chat encrypted
    • Secure transfer
    • File requests
    • Backup
    • Camera upload
    • En İyi Kullanım: Büyük dosya depolama
    • Web: https://mega.io

    P2P ve Direct File Transfer¶

    6. WeTransfer¶

    • Platform: Web, iOS, Android
    • Fiyat: Ücretsiz (2GB) / Ücretli (Pro - $10-20/ay)
    • Özellikers:
    • Large file transfer (up to 200GB)
    • Simple interface
    • Email transfer
    • Link transfer
    • Password protection
    • Transfer tracking
    • Expiration date
    • En İyi Kullanım: Quick large file transfer
    • Web: https://wetransfer.com

    7. Send Anywhere¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (10GB) / Ücretli (Pro - $9.99/month)
    • Özellikers:
    • P2P file transfer
    • 6-digit key
    • Email
    • Link
    • QR code
    • Transfer large files
    • No size limit (Pro)
    • Cross-device
    • En İyi Kullanım: Quick file transfer
    • Web: https://send-anywhere.com

    8. Resilio Sync¶

    • Platform: Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz / Ücretli (Pro - $8/month)
    • Özellikers:
    • P2P sync
    • No cloud
    • Direct device-to-device
    • Selective sync
    • Encrypted
    • Fast
    • Bandwidth control
    • LAN sync
    • En İyi Kullanım: P2P sync
    • Web: https://www.resilio.com

    9. Syncthing¶

    • Platform: Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Open source
    • P2P sync
    • No cloud
    • Cross-platform
    • Encrypted
    • Continuous sync
    • Selective sync
    • Web UI
    • En İyi Kullanım: Open-source P2P sync
    • Web: https://syncthing.net

    10. BitTorrent Sync (Resilio Sync)¶

    • Platform: Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz / Ücretli (Pro - $8/month)
    • Özellikers:
    • P2P sync
    • No cloud
    • Fast
    • Encrypted
    • Selective sync
    • Bandwidth control
    • LAN sync
    • Cross-device
    • En İyi Kullanım: P2P sync
    • Web: https://www.resilio.com

    FTP/SFTP Client'ları¶

    11. FileZilla¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Open source
    • FTP, FTPS, SFTP
    • Drag-and-drop
    • Site manager
    • Transfer queue
    • Transfer resume
    • File comparison
    • Proxy support
    • En İyi Kullanım: Free FTP client
    • Web: https://filezilla-project.org

    12. Cyberduck¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz (donation requested)
    • Özellikers:
    • FTP, SFTP, WebDAV, S3, etc.
    • Drag-and-drop
    • Bookmark
    • Edit files
    • Encryption
    • Resume transfers
    • Transfers window
    • En İyi Kullanım: Mac & Windows FTP
    • Web: https://cyberduck.io

    13. WinSCP¶

    • Platform: Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Open source
    • SFTP, SCP, FTP, WebDAV
    • Windows-like interface
    • Scripting
    • File synchronization
    • Internal editor
    • PuTTY integration
    • Commander interface
    • En İyi Kullanım: Windows SFTP client
    • Web: https://winscp.net

    14. Transmit¶

    • Platform: macOS
    • Fiyat: Ücretli ($45)
    • Özellikers:
    • Mac optimize
    • FTP, SFTP, S3, WebDAV
    • Beautiful UI
    • Panic Sync
    • iCloud Drive support
    • Edit files
    • Transfers
    • Favorites
    • En İyi Kullanım: Mac FTP client
    • Web: https://panic.com/transmit

    15. ForkLift¶

    • Platform: macOS
    • Fiyat: Ücretli ($9.99/month or $49.99)
    • Özellikers:
    • Mac FTP/SFTP client
    • Remote connections
    • Synchronization
    • Compare folders
    • Mount remote drives
    • Edit files
    • Dropstack
    • Panes
    • En İyi Kullanım: Mac FTP & remote
    • Web: https://binarynights.com

    Local File Sync¶

    16. FreeFileSync¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Open source
    • Folder synchronization
    • Visual comparison
    • Two-way / mirror
    • Schedule
    • Real-time sync
    • Network drives
    • Versioning
    • En İyi Kullanım: Free folder sync
    • Web: https://freefilesync.org

    17. GoodSync¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz (limited) / Ücretli ($29.95/year)
    • Özellikers:
    • File synchronization
    • Backup
    • Real-time sync
    • Schedule
    • SFTP, FTP, WebDAV, S3
    • Versioning
    • Multi-platform
    • En İyi Kullanım: Backup & sync
    • Web: https://www.goodsync.com

    18. SyncBackFree¶

    • Platform: Windows
    • Fiyat: Ücretsiz / Ücretli (Pro - $39.95, SE - $54.95)
    • Özellikers:
    • Backup & sync
    • Schedule
    • Compression
    • Encryption
    • FTP, SFTP, network
    • Email notifications
    • Versioning
    • En İyi Kullanım: Windows backup
    • Web: https://www.2brightsparks.com/freeware

    19. Beyond Compare¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz deneme / Ücretli ($30-40)
    • Özellikers:
    • File & folder comparison
    • Visual diff
    • Merge
    • Synchronization
    • FTP, SFTP, S3
    • Schedule
    • Scripting
    • En İyi Kullanım: Advanced file comparison
    • Web: https://www.scootersoftware.com

    20. rsync¶

    • Platform: Linux, macOS, Windows (via Cygwin)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikers:
    • Open source
    • File sync
    • Incremental transfers
    • Compression
    • SSH support
    • Mirror, update
    • Bandwidth limiting
    • Cross-platform
    • En İyi Kullanım: Command-line sync
    • Web: https://rsync.samba.org
