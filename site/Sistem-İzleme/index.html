    SİSTEM İZLEME VE PERFORMANS ARAÇLARI¶

    Sistem İzleme¶

    1. Task Manager (Windows)¶

    • Platform: Windows
    • Fiyat: Ücretsiz (Windows ile birlikte)
    • Özellikler:
    • Process monitoring
    • CPU, Memory, Disk, Network usage
    • Performance graphs
    • Startup apps
    • Services
    • Process details
    • End task
    • En İyi Kullanım: Windows temel sistem izleme
    • Web: Built-in to Windows

    2. Activity Monitor (macOS)¶

    • Platform: macOS
    • Fiyat: Ücretsiz (macOS ile birlikte)
    • Özellikler:
    • CPU, Memory, Energy, Disk, Network
    • Process monitoring
    • Force quit
    • View detailed process info
    • Energy impact
    • Memory pressure
    • Disk activity
    • En İyi Kullanım: Mac temel sistem izleme
    • Web: Built-in to macOS

    3. htop¶

    • Platform: Linux, macOS (via Homebrew), Windows (via WSL)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Interactive process viewer
    • CPU, Memory usage
    • Process management
    • Process tree
    • Kill processes
    • Color-coded
    • Customizable
    • En İyi Kullanım: Linux terminal sistem izleme
    • Web: https://htop.dev

    4. Process Explorer¶

    • Platform: Windows
    • Fiyat: Ücretsiz
    • Özellikler:
    • Advanced process viewer
    • Process tree
    • Handles & DLLs
    • CPU usage
    • Memory usage
    • Kill process
    • Search
    • System info
    • En İyi Kullanım: Windows detaylı process monitoring
    • Web: https://learn.microsoft.com/sysinternals/downloads/process-explorer

    5. Resource Monitor¶

    • Platform: Windows
    • Fiyat: Ücretsiz (Windows ile birlikte)
    • Özellikler:
    • CPU, Memory, Disk, Network detailed monitoring
    • Processes with handles
    • Disk activity
    • Network connections
    • File handles
    • Real-time graphs
    • En İyi Kullanım: Windows kaynak detayları
    • Web: Built-in to Windows

    Advanced Sistem İzleme¶

    6. HWiNFO¶

    • Platform: Windows
    • Fiyat: Ücretsiz
    • Özellikler:
    • Hardware monitoring
    • CPU, GPU, Memory, Motherboard, etc.
    • Temperature
    • Voltage
    • Fan speeds
    • Power consumption
    • Real-time monitoring
    • Reports
    • En İyi Kullanım: Hardware monitoring
    • Web: https://www.hwinfo.com

    7. CPU-Z¶

    • Platform: Windows, Android
    • Fiyat: Ücretsiz
    • Özellikler:
    • CPU details
    • Mainboard
    • Memory
    • Graphics
    • Benchmarks
    • Save reports
    • En İyi Kullanım: CPU & system info
    • Web: https://www.cpuid.com/softwares/cpu-z.html

    8. GPU-Z¶

    • Platform: Windows
    • Fiyat: Ücretsiz
    • Özellikler:
    • GPU details
    • Memory
    • Graphics clock
    • Sensors (temperature, fan speed)
    • Display adapter info
    • Save reports
    • En İyi Kullanım: GPU monitoring
    • Web: https://www.techpowerup.com/gpu-z/

    9. HWMonitor¶

    • Platform: Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz / Ücretli (Pro - $19.95)
    • Özellikler:
    • Hardware monitoring
    • Temperature, voltage, fan speed
    • CPU, GPU, Motherboard, Disk, etc.
    • Real-time monitoring
    • Alerts
    • En İyi Kullanım: Hardware sensors
    • Web: https://www.cpuid.com/softwares/hwmonitor.html

    10. iStat Menus¶

    • Platform: macOS
    • Fiyat: Ücretli ($14.39)
    • Özellikler:
    • Menu bar monitoring
    • CPU, Memory, Network, Disk, Sensors
    • Battery
    • Time
    • Weather
    • Fan speed
    • Customizable
    • En İyi Kullanım: Mac menubar monitoring
    • Web: https://bjango.com/mac/istatmenus

    Performance Monitoring¶

    11. PerfMon (Windows Performance Monitor)¶

    • Platform: Windows
    • Fiyat: Ücretsiz (Windows ile birlikte)
    • Özellikler:
    • Performance counters
    • Real-time graphs
    • Data collector sets
    • Reports
    • Custom counters
    • Alerts
    • Long-term monitoring
    • En İyi Kullanım: Windows performance data
    • Web: Built-in to Windows

    12. Glances¶

    • Platform: Linux, macOS, Windows (via Python)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • System monitoring
    • CPU, Memory, Disk, Network
    • Processes
    • Web interface
    • Export (CSV, JSON)
    • Alert thresholds
    • En İyi Kullanım: Linux monitoring tool
    • Web: https://nicolargo.github.io/glances

    13. nmon (Nigel's Monitor)¶

    • Platform: Linux, AIX
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • System monitoring
    • CPU, Memory, Disk, Network
    • Processes
    • NFS
    • Top processes
    • Save data
    • Curses UI
    • En İyi Kullanım: Linux & AIX monitoring
    • Web: https://sourceforge.net/projects/nmon

    14. Netdata¶

    • Platform: Linux, macOS, FreeBSD, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Real-time monitoring
    • 1000+ metrics
    • Web dashboard
    • CPU, Memory, Disk, Network
    • Applications
    • Alerts
    • Plugins
    • En İyi Kullanım: Real-time dashboard
    • Web: https://www.netdata.cloud

    15. Prometheus¶

    • Platform: Linux, macOS, Windows (via binary)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Time-series database
    • Metrics collection
    • Querying (PromQL)
    • Alerting
    • Grafana integration
    • Service discovery
    • En İyi Kullanım: Monitoring & alerting system
    • Web: https://prometheus.io

    Enterprise Monitoring¶

    16. Zabbix¶

    • Platform: Linux, Windows, macOS
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Monitoring
    • Alerting
    • Distributed monitoring
    • Network, server, application monitoring
    • Triggers
    • Maps
    • Reports
    • Auto-discovery
    • En İyi Kullanım: Enterprise monitoring
    • Web: https://www.zabbix.com

    17. Nagios Core¶

    • Platform: Linux, Windows, macOS
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Host & service monitoring
    • Alerting
    • Plugins
    • Distributed monitoring
    • Status maps
    • Reports
    • En İyi Kullanım: Infrastructure monitoring
    • Web: https://www.nagios.org

    18. Grafana¶

    • Platform: Linux, Windows, macOS
    • Fiyat: Ücretsiz (Community) / Ücretli (Enterprise)
    • Özellikler:
    • Open source
    • Visualization
    • Dashboards
    • Multiple data sources (Prometheus, InfluxDB, etc.)
    • Alerting
    • Panels & variables
    • Annotations
    • En İyi Kullanım: Metrics visualization
    • Web: https://grafana.com

    19. Telegraf¶

    • Platform: Linux, Windows, macOS
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Metrics collector
    • 200+ input plugins
    • Output plugins (InfluxDB, Prometheus, etc.)
    • Process monitoring
    • System monitoring
    • En İyi Kullanım: Metrics collection
    • Web: https://www.influxdata.com/time-series-platform/telegraf

    20. InfluxDB¶

    • Platform: Linux, Windows, macOS
    • Fiyat: Ücretsiz (Community) / Ücretli (Enterprise)
    • Özellikler:
    • Open source
    • Time-series database
    • Metrics storage
    • Query language (InfluxQL, Flux)
    • Data retention
    • High performance
    • En İyi Kullanım: Time-series data storage
    • Web: https://www.influxdata.com
