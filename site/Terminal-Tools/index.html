    Terminal Tools

    TERMINAL VE COMMAND LINE TOOLS¶

    Advanced Terminal Emülatörleri¶

    1. iTerm2¶

    • Platform: macOS
    • Fiyat: Ücretsiz
    • Özellikler:
    • Mac için gelişmiş terminal
    • Split panes
    • Search
    • Copy/Paste history
    • Profiles
    • Hotkey window
    • Shell integration
    • tmux integration
    • Image support
    • En İyi Kullanım: Mac power users
    • Web: https://iterm2.com

    2. Windows Terminal¶

    • Platform: Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Modern terminal
    • Multiple tabs
    • Split panes
    • GPU acceleration
    • Customizable themes
    • Profiles (PowerShell, CMD, WSL, etc.)
    • Unicode support
    • Keyboard shortcuts
    • En İyi Kullanım: Windows terminal
    • Web: https://github.com/microsoft/terminal

    3. Alacritty¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • GPU-accelerated
    • Fast
    • Cross-platform
    • Minimal config
    • Copy/Paste
    • Scrollback
    • En İyi Kullanım: High-performance terminal
    • Web: https://alacritty.org

    4. Kitty¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • GPU-accelerated
    • Kitten (framework)
    • SSH kitten
    • Split panes
    • Hyperlinks
    • Unicode support
    • Fast
    • En İyi Kullanım: Fast GPU terminal
    • Web: https://sw.kovidgoyal.net/kitty

    5. Terminology¶

    • Platform: Linux (Enlightenment)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Embedded media
    • Thumbnails
    • Tabbed browsing
    • Theming
    • Emoji support
    • Copy/Paste
    • Split panes
    • En İyi Kullanım: Linux rich terminal
    • Web: https://www.enlightenment.org/about-terminology

    Modern Shells¶

    6. Zsh (Z Shell)¶

    • Platform: Linux, macOS
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Advanced shell
    • Tab completion
    • Globbing
    • Theme support
    • Oh My Zsh framework
    • Customizable
    • En İyi Kullanım: Modern shell
    • Web: https://www.zsh.org

    7. Fish Shell¶

    • Platform: Linux, macOS, Windows (via WSL)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • User-friendly
    • Autosuggestions
    • Syntax highlighting
    • Web-based configuration
    • Auto-completion
    • Scriptable
    • En İyi Kullanım: User-friendly shell
    • Web: https://fishshell.com

    8. PowerShell¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Object-oriented
    • Scripting
    • Pipeline
    • Modules
    • .NET integration
    • Cross-platform
    • Administrative tasks
    • En İyi Kullanım: Windows automation
    • Web: https://github.com/PowerShell/PowerShell

    9. Nu Shell¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:

    • Plugins
    • Cross-platform
    • Modern syntax
    • En İyi Kullanım: Modern data-oriented shell
    • Web: https://www.nushell.sh

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • User-friendly

    Text Editors (Terminal)¶

    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:

    • Modal editing
    • Powerful plugins
    • Macros
    • Scripting (Vimscript)
    • Syntax highlighting
    • Lightweight
    • Remote editing (via SSH)
    • En İyi Kullanım: Terminal text editing
    • Web: https://www.vim.org

    • Asynchronous I/O
    • Modern features
    • Extensible
    • Plugin ecosystem
    • En İyi Kullanım: Modern Vim
    • Web: https://neovim.io

    • En İyi Kullanım: Extensible editor
