    Disk Analizi Temizlik

    DİSK ANALİZİ VE TEMİZLİK¶

    Disk Analizi Araçları¶

    1. WinDirStat¶

    • Platform: Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Disk usage visualization
    • Treemap view
    • File type breakdown
    • Extension list
    • Clean up files
    • Open containing folder
    • Open file
    • Command properties
    • En İyi Kullanım: Windows disk space analyzer
    • Web: https://windirstat.net

    2. WizTree¶

    • Platform: Windows
    • Fiyat: Ücretsiz / Ücretli (Portable version)
    • Özellikler:
    • Fast disk scanning (MFT)
    • Treemap view
    • File list view
    • Filter
    • Delete files
    • File attributes
    • Portable
    • En İyi Kullanım: Hızlı disk analizi (Windows)
    • Web: https://wiztreefree.com

    3. Disk Inventory X¶

    • Platform: macOS
    • Fiyat: Ücretsiz
    • Özellikler:
    • Disk usage visualization
    • Treemap
    • File browser
    • File types
    • Open & delete files
    • Sort options
    • Finder integration
    • En İyi Kullanım: Mac disk analyzer
    • Web: http://www.derlien.com

    4. DaisyDisk¶

    • Platform: macOS
    • Fiyat: Ücretli ($9.99)
    • Özellikler:
    • Beautiful interface
    • Treemap visualization
    • Scan local & network drives
    • Clean up files
    • Move to trash
    • Drag & drop
    • Multiple scans
    • En İyi Kullanım: Mac için modern disk analyzer
    • Web: https://daisydiskapp.com

    5. ncdu (NCurses Disk Usage)¶

    • Platform: Linux, macOS, Windows (via WSL)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Terminal based
    • Fast scanning
    • Navigate directories
    • Delete files
    • Sort by size
    • Lightweight
    • Remote SSH
    • En İyi Kullanım: Linux ve terminal disk analizi
    • Web: https://dev.yorhel.nl/ncdu

    6. TreeSize Free¶

    • Platform: Windows
    • Fiyat: Ücretsiz / Ücretli (Professional - $49.95)
    • Özellikler:
    • Disk space usage
    • Tree view
    • Charts
    • File types
    • File ages
    • Export (XLS, CSV, etc.)
    • Command line support (Pro)
    • Multiple scan options (Pro)
    • En İyi Kullanım: Windows disk space
    • Web: https://www.jam-software.com/treesize_free

    7. QDirStat¶

    • Platform: Linux, Windows, macOS
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Treemap visualization
    • File type breakdown
    • Clean up files
    • Recursive size calculation
    • Color coding
    • KDE app
    • En İyi Kullanım: Linux disk analyzer
    • Web: https://github.com/shundhammer/qdirstat

    8. GrandPerspective¶

    • Platform: macOS
    • Fiyat: Ücretsiz
    • Özellikler:
    • Disk usage visualization
    • Treemap
    • File types
    • Scan drives
    • Open & delete files
    • Filter by type
    • Export
    • En İyi Kullanım: Mac için open-source analyzer
    • Web: https://grandperspectiv.sourceforge.net

    9. SpaceMonger¶

    • Platform: Windows
    • Fiyat: Ücretsiz (version 2.1) / Ücretli (version 4 - $14.99)
    • Özellikler:
    • Treemap visualization
    • Disk usage
    • File details
    • Open, delete, rename
    • File age
    • Multiple views
    • Network drives
    • En İyi Kullanım: Windows disk usage
    • Web: https://www.sixty-five.cc/sm

    10. OmniDiskSweeper¶

    • Platform: macOS
    • Fiyat: Ücretsiz (macOS)
    • Özellikler:
    • Scan folders
    • File sizes
    • Sort by size
    • Delete files
    • Simple interface
    • Finder integration
    • En İyi Kullanım: Mac basit disk cleaner
    • Web: https://www.omnigroup.com/omnidisksweeper

    Sistem Temizleme¶

    11. CCleaner¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz / Ücretli (Professional - $29.95/year)
    • Özellikler:
    • Clean temporary files
    • Registry cleaner
    • Browser cleaner
    • Startup manager
    • Software uninstaller
    • Duplicate finder (Pro)
    • Disk analyzer (Pro)
    • Driver updater (Pro)
    • En İyi Kullanım: Popüler sistem temizleyici
    • Web: https://www.ccleaner.com

    12. BleachBit¶

    • Platform: Windows, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Clean temp files, cache, logs
    • Shred files
    • Wipe free space
    • Custom cleaners
    • Command line
    • Portable
    • En İyi Kullanım: Linux ve Windows open-source cleaner
    • Web: https://www.bleachbit.org

    13. Avast Cleanup¶

    • Platform: Windows, macOS
    • Fiyat: Ücretli ($59.99/year)
    • Özellikler:
    • Junk files cleaner
    • Registry cleaner
    • Browser cleaner
    • Bloatware remover
    • Software updater
    • Speed up
    • Disk cleaner
    • En İyi Kullanım: Avast güvenlik paketiyle
    • Web: https://www.avast.com/cleanup

    14. Advanced SystemCare¶

    • Platform: Windows
    • Fiyat: Ücretsiz / Ücretli (Pro - $19.99/year)
    • Özellikler:
    • System optimizer
    • Junk cleaner
    • Registry fix
    • Privacy sweep
    • Startup optimizer
    • Browser protection
    • RAM cleaner
    • Speed up
    • En İyi Kullanım: Kapsamlı Windows temizleyici
    • Web: https://www.iobit.com/advancedsystemcare

    15. Glary Utilities¶

    • Platform: Windows
    • Fiyat: Ücretsiz / Ücretli (Pro - $39.95/year)
    • Özellikler:
    • Disk cleaner
    • Registry cleaner
    • Startup manager
    • Duplicate finder
    • Empty folders finder
    • File encryption/decryption
    • File shredder
    • System tools
    • En İyi Kullanım: All-in-one Windows utilities
    • Web: https://www.glarysoft.com
