    AĞ ANALİZİ VE NETWORK ARAÇLARI¶

    Network Analyzer ve Scanner'lar¶

    1. Wireshark¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Deep packet inspection
    • Protocol analyzer
    • Live capture
    • Read/write many formats (pcap, pcapng, etc.)
    • Filters & display filters
    • Decryption (SSL/TLS)
    • Packet coloring
    • Export objects
    • Statistics & graphs
    • En İyi Kullanım: Deep packet analysis
    • Web: https://www.wireshark.org

    2. Nmap (Network Mapper)¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Network discovery
    • Port scanning
    • Service detection
    • OS detection
    • NSE (Nmap Scripting Engine)
    • Output formats (XML, JSON, etc.)
    • Firewall evasion
    • En İyi Kullanım: Network scanning & discovery
    • Web: https://nmap.org

    3. Fing¶

    • Platform: Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz / Ücretli (Desktop Pro - $29.99)
    • Özellikler:
    • Network scanner
    • Device discovery
    • Port scanning
    • IP address lookup
    • Network speed test
    • Wake-on-LAN
    • Security analysis
    • En İyi Kullanım: Quick network scanner
    • Web: https://www.fing.com

    4. Advanced IP Scanner¶

    • Platform: Windows
    • Fiyat: Ücretsiz
    • Özellikler:
    • Network scanning
    • IP range scanning
    • MAC address detection
    • Remote control
    • Wake-on-LAN
    • Share folders
    • HTTP, HTTPS, RDP access
    • En İyi Kullanım: Windows network scanner
    • Web: https://www.advanced-ip-scanner.com

    5. Angry IP Scanner¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • IP range scanning
    • Port scanning
    • Ping
    • NetBIOS
    • Fetchers
    • Export results (CSV, TXT, etc.)
    • Extensible via plugins
    • En İyi Kullanım: Cross-platform IP scanner
    • Web: https://angryip.org

    Network Monitoring¶

    6. PRTG Network Monitor¶

    • Platform: Windows
    • Fiyat: Ücretsiz (100 sensors) / Ücretli ($1,499-14,999/year)
    • Özellikler:
    • Network monitoring
    • Sensors (Ping, SNMP, etc.)
    • Alerts & notifications
    • Maps
    • Dashboards
    • Reports
    • Auto-discovery
    • Distributed monitoring
    • En İyi Kullanım: Enterprise network monitoring
    • Web: https://www.paessler.com/prtg

    7. SolarWinds Network Performance Monitor¶

    • Platform: Windows
    • Fiyat: Ücretli ($2,386-10,703/year)
    • Özellikler:
    • Network performance monitoring
    • Device monitoring
    • Performance baselines
    • Alerting
    • NetFlow analysis
    • Network visualization
    • Custom alerts
    • Reports
    • En İyi Kullanım: Enterprise network monitoring
    • Web: https://www.solarwinds.com/network-performance-monitor

    8. ManageEngine OpManager¶

    • Platform: Windows, Linux
    • Fiyat: Ücretsiz (monitor 10 devices) / Ücretli ($711-15,595/year)
    • Özellikler:
    • Network monitoring
    • Server monitoring
    • Physical & virtual server monitoring
    • Application monitoring
    • Traffic analysis
    • Alerting
    • Reports
    • Maps
    • En İyi Kullanım: Comprehensive network monitoring
    • Web: https://www.manageengine.com/network-monitoring

    9. Zenoss¶

    • Platform: Linux
    • Fiyat: Ücretsiz (Community) / Ücretli (Enterprise)
    • Özellikler:
    • Infrastructure monitoring
    • Network monitoring
    • Auto-discovery
    • Event management
    • Alerting
    • Service impact
    • Root cause analysis
    • En İyi Kullanım: Open-source infrastructure monitoring
    • Web: https://www.zenoss.com

    10. Zabbix¶

    • Platform: Linux, Windows, macOS
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Network monitoring
    • Host & service monitoring
    • Triggers & alerts
    • Network maps
    • Distributed monitoring
    • Reports
    • Customizable
    • En İyi Kullanım: Open-source network monitoring
    • Web: https://www.zabbix.com

    Packet Capture ve Analysis¶

    11. tcpdump¶

    • Platform: Linux, macOS, Windows (via WinDump)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Packet capture
    • Filters
    • Save to file (pcap)
    • Read from file
    • Command-line
    • Wide protocol support
    • Real-time analysis
    • En İyi Kullanım: Packet capture
    • Web: https://www.tcpdump.org

    12. tshark (Wireshark CLI)¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Wireshark CLI
    • Packet capture & analysis
    • Filters
    • Output formats (JSON, XML, etc.)
    • Statistics
    • Decryption
    • En İyi Kullanım: Wireshark command-line tool
    • Web: https://www.wireshark.org/docs/man-pages/tshark.html

    13. Ettercap¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Man-in-the-middle (MITM) attacks
    • Packet filtering
    • Content filtering
    • Network discovery
    • SSL stripping
    • Password sniffing
    • En İyi Kullanım: MITM & security testing
    • Web: https://ettercap.github.io

    14. Cain & Abel¶

    • Platform: Windows
    • Fiyat: Ücretsiz
    • Özellikler:
    • Password recovery
    • Sniffer
    • Network analysis
    • ARP poisoning
    • Password cracking
    • Rainbow tables
    • En İyi Kullanım: Network security testing (Windows)
    • Web: https://www.oxid.it/cain.html

    15. Colasoft Capsa¶

    • Platform: Windows
    • Fiyat: Ücretli ($299-999)
    • Özellikler:
    • Network analyzer
    • Packet capture
    • Protocol analysis
    • Real-time monitoring
    • VoIP monitoring
    • Expert analysis
    • Alerts
    • En İyi Kullanım: Network analysis & troubleshooting
    • Web: https://www.colasoft.com/capsa

    Network Diagnostics¶

    16. PingPlotter¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz (Basic) / Ücretli (Pro - $29.99-39.99/month)
    • Özellikler:
    • Network latency monitoring
    • Continuous ping
    • Traceroute
    • Graphs
    • Packet loss
    • Jitter
    • Alerts
    • Historical data
    • En İyi Kullanım: Network troubleshooting
    • Web: https://www.pingplotter.com

    17. NetSpot¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz (Home) / Ücretli (Pro - $49, Enterprise - $199)
    • Özellikler:
    • WiFi heatmap
    • WiFi survey
    • Signal strength
    • Channel interference
    • Spectrum analysis
    • Network discovery
    • Planning tool
    • En İyi Kullanım: WiFi analysis
    • Web: https://www.netspotapp.com

    18. inSSIDer¶

    • Platform: Windows, macOS
    • Fiyat: Ücretli ($19.99/month)
    • Özellikler:
    • WiFi scanner
    • Signal strength
    • Channel interference
    • Security assessment
    • Network discovery
    • Real-time monitoring
    • En İyi Kullanım: WiFi troubleshooting
    • Web: https://www.metageek.com/products/inssider

    19. Traceroute¶

    • Platform: Windows (tracert), Linux, macOS
    • Fiyat: Ücretsiz (built-in)
    • Özellikler:
    • Route tracing
    • Hop-by-hop latency
    • Network path discovery
    • Built-in to OS
    • Command-line
    • En İyi Kullanım: Network path analysis
    • Web: Built-in tool

    20. MTR (My Traceroute)¶

    • Platform: Linux, macOS, Windows (via WinMTR)
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • Traceroute + ping
    • Continuous monitoring
    • Packet loss & jitter
    • Graphical interface
    • Real-time stats
    • En İyi Kullanım: Advanced traceroute
    • Web: https://www.bitwizard.nl/mtr
