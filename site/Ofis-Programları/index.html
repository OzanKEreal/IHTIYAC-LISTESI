    OFİS PROGRAMLARI VE ÜRETKENLİK¶

    Kapsamlı Ofis Suite'leri¶

    1. Microsoft 365¶

    • Platform: Windows, macOS, iOS, Android, Web
    • Fiyat: Ücretsiz (Web) / Ücretli ($6.99-20.00/ay)
    • Özellikler:
    • Word, Excel, PowerPoint, Outlook
    • OneDrive (1TB cloud storage)
    • Teams (sürümlerinde)
    • Collaboration
    • AutoSave
    • Desktop & mobile
    • AI-powered features
    • Premium templates
    • En İyi Kullanım: İş dünyası standart ofis suite
    • Web: https://www.microsoft.com/microsoft-365

    2. Google Workspace¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (Personal) / Ücretli ($6-18/ay)
    • Özellikler:
    • Docs, Sheets, Slides, Forms
    • Gmail
    • Google Drive
    • Real-time collaboration
    • Cloud-based
    • Offline mode
    • Version history
    • Add-ons
    • En İyi Kullanım: Cloud-based collaboration
    • Web: https://workspace.google.com

    3. LibreOffice¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Writer (Word alternatifi)
    • Calc (Excel alternatifi)
    • Impress (PowerPoint alternatifi)
    • Draw, Math, Base
    • Microsoft format destekli
    • Extensions
    • Templates
    • En İyi Kullanım: Ücretsiz Microsoft Office alternatifi
    • Web: https://www.libreoffice.org

    4. Apache OpenOffice¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Writer, Calc, Impress
    • Draw, Math, Base
    • ODF ve MS formatları
    • Extensions
    • Dictionary tools
    • Templates
    • En İyi Kullanım: Açık kaynak ofis suite
    • Web: https://www.openoffice.org

    5. Zoho Workplace¶

    • Platform: Web, Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz (Basic) / Ücretli ($3-6/ay)
    • Özellikler:
    • Writer, Sheet, Show
    • Mail, Cliq, WorkDrive
    • Collaboration
    • Cloud storage
    • Integrations
    • Version control
    • Mobile apps
    • En İyi Kullanım: Küçük işletmeler ve ekipler
    • Web: https://www.zoho.com/workplace
