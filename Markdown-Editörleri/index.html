    MARKDOWN EDİTÖRLERİ VE DOKÜMANLAR¶

    Markdown Editörleri¶

    1. Typora¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz (beta) / Ücretli ($14.99 one-time)
    • Özellikler:
    • What You See Is What You Mean (WYSIWYM)
    • Live preview
    • Focus mode
    • Typewriter mode
    • Image support
    • Export (HTML, PDF, Word, etc.)
    • Tables
    • MathJax (LaTeX)
    • En İyi Kullanım: Seamless markdown editing
    • Web: https://typora.io

    2. VS Code¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz
    • Özellikler:
    • Markdown support built-in
    • Preview
    • Syntax highlighting
    • Extensions (Markdown All in One, etc.)
    • Integrated terminal
    • Git integration
    • Multi-cursor editing
    • En İyi Kullanım: Markdown in VS Code
    • Web: https://code.visualstudio.com

    3. MacDown¶

    • Platform: macOS
    • Fiyat: Ücretsiz
    • Özellikler:
    • Open source
    • Live preview
    • Custom themes
    • MathJax
    • GFM (GitHub Flavored Markdown)
    • Tables
    • TOC (Table of Contents)
    • En İyi Kullanım: Mac markdown editor
    • Web: https://macdown.uranusjr.com

    4. Obsidian¶

    • Platform: Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz / Ücretli (Sync, Publish - $4-50/month)
    • Özellikler:
    • Markdown-based
    • Bi-directional linking
    • Graph view
    • Plugins
    • Themes
    • Canvas (visual notes)
    • Publish
    • Sync
    • En İyi Kullanım: Personal knowledge base
    • Web: https://obsidian.md

    5. Logseq¶

    • Platform: Windows, macOS, iOS, Android
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:

    • Markdown & Org-mode

    • Graph view
    • Journaling
    • PDF annotation
    • Plugins
    • En İyi Kullanım: Open-source PKB
    • Web: https://logseq.com

    6. Joplin¶

    • Platform: Windows, macOS, iOS, Android, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:

    • Plugins
    • En İyi Kullanım: Encrypted notes
    • Web: https://joplinapp.org
