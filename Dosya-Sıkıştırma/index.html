    DOSYA SIKIŞTIRMA VE ARŞİVLEME¶

    Popüler Arşiv Programları¶

    1. WinRAR¶

    • Platform: Windows
    • Fiyat: Ücretsiz deneme / Ücretli ($29 one-time)
    • Özellikler:
    • RAR, ZIP, 7Z, CAB, ARJ, LZH, TAR, GZ, ACE, UUE, BZ2, JAR, ISO, Z, 7-Zip
    • Şifre koruması
    • Recovery record
    • Solid arşivleme
    • Multi-volume
    • Self-extracting arşivler
    • Integration (Windows)
    • En İyi Kullanım: Windows için standart arşiv programı
    • Web: https://www.win-rar.com

    2. 7-Zip¶

    • Platform: Windows, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • High compression (7z)
    • Formats: 7z, ZIP, GZIP, BZIP2, TAR
    • AES-256 encryption
    • Integration (Windows)
    • Command line
    • Self-extracting
    • Multi-language
    • En İyi Kullanım: Ücretsiz open-source alternatif
    • Web: https://www.7-zip.org

    3. WinZip¶

    • Platform: Windows, macOS
    • Fiyat: Ücretsiz deneme / Ücretli ($29.95-59.95/year)
    • Özellikler:
    • ZIP, ZIPX, RAR, 7Z, LHA, CAB
    • Encryption
    • Cloud integration (Dropbox, Google Drive, OneDrive)
    • File sharing
    • PDF conversion
    • Watermark
    • Compression modes
    • Multi-volume
    • En İyi Kullanım: Windows & Mac için profesyonel arşivleme
    • Web: https://www.winzip.com

    4. PeaZip¶

    • Platform: Windows, macOS, Linux
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Open source
    • 150+ formats (7z, ARC, BR, BZ2, GZ, PAQ, PEA, RAR, TAR, WIM, ZIP, ZIPX)
    • Encryption (AES-256)
    • Two-factor authentication
    • Secure delete
    • File splitting
    • Self-extracting
    • Cross-platform
    • En İyi Kullanım: Cross-platform arşivleme
    • Web: https://peazip.github.io

    5. Bandizip¶

    • Platform: Windows
    • Fiyat: Ücretsiz (non-commercial) / Ücretli (Pro - $29 one-time)
    • Özellikler:
    • Formats: ZIP, 7Z, RAR, ALZ, EGG, TAR, BH, LZH, GZ, BZ2, ISO, CAB, WIM, XZ
    • Encryption
    • Preview files
    • Image preview
    • Cloud integration
    • Multi-volume
    • Self-extracting
    • Unicode support
    • En İyi Kullanım: Windows için modern arşivleyici
    • Web: https://en.bandisoft.com/bandizip

    Mac Özel Arşivleme¶

    6. The Unarchiver¶

    • Platform: macOS
    • Fiyat: Ücretsiz
    • Özellikler:
    • Extract: ZIP, RAR, 7Z, TAR, GZ, BZ2, LHA, etc.
    • Simple interface
    • Built-in macOS
    • Character encoding
    • Quick extraction
    • En İyi Kullanım: Mac için standart extractor
    • Web: https://theunarchiver.com

    7. Keka¶

    • Platform: macOS
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Compress & extract: 7z, ZIP, TAR, GZ, BZ2, DMG, ISO
    • Encryption (AES-256)
    • Drag-and-drop
    • Context menu
    • Custom compression level
    • Split archives
    • Self-extracting (7z)
    • En İyi Kullanım: Mac için all-in-one arşivleyici
    • Web: https://www.keka.io

    8. BetterZip¶

    • Platform: macOS
    • Fiyat: Ücretli ($24.95)
    • Özellikler:
    • Compress & extract: 30+ formats
    • Encryption
    • Multi-volume
    • Preview files
    • Archive search
    • Finder integration
    • Archive password manager
    • Share to services
    • En İyi Kullanım: Mac için profesyonel arşivleme
    • Web: https://macitbetter.com

    9. Archiver¶

    • Platform: macOS
    • Fiyat: Ücretli ($19)
    • Özellikler:
    • Simple interface
    • Compress & extract
    • Encryption
    • Preview
    • Split archives
    • Create archives
    • Drag-and-drop
    • En İyi Kullanım: Mac için basit arşivleme
    • Web: https://marcinmichalik.com/archiver

    10. StuffIt Deluxe¶

    • Platform: macOS
    • Fiyat: Ücretli ($49.99 one-time)
    • Özellikler:
    • SIT format (Mac exclusive)
    • Encryption
    • Compression optimization
    • Cloud integration
    • File sharing
    • Archive repair
    • Schedules
    • En İyi Kullanım: Mac için StuffIt format desteği
    • Web: https://www.smithmicro.com/stuffit

    Command Line Tools¶

    16. tar (Unix)¶

    • Platform: Linux, macOS, Windows (via WSL)
    • Fiyat: Ücretsiz
    • Özellikler:
    • Open source
    • Standard Unix archive
    • Compression (gzip, bzip2, xz)
    • Preserves permissions
    • Incremental backups
    • Widely used
    • En İyi Kullanım: Unix-style arşivleme
    • Web: https://www.gnu.org/software/tar

    17. gzip¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Standard compression
    • Fast
    • Widely compatible
    • Command line
    • Decompression
    • En İyi Kullanım: Gzip dosyaları
    • Web: https://www.gnu.org/software/gzip

    18. bzip2¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • High compression
    • Slower than gzip
    • Good for text files
    • Command line
    • Decompression
    • En İyi Kullanım: Yüksek sıkıştırma ihtiyacı
    • Web: https://sourceware.org/bzip2

    19. xz¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • LZMA compression
    • Very high compression
    • Slow compression, fast decompression
    • Command line
    • Modern standard
    • En İyi Kullanım: Yüksek sıkıştırma ihtiyacı
    • Web: https://tukaani.org/xz

    20. zstd (Zstandard)¶

    • Platform: Linux, macOS, Windows
    • Fiyat: Ücretsiz ve Açık Kaynak
    • Özellikler:
    • Fast compression & decompression
    • Good compression ratio
    • Modern standard
    • Command line
    • Wide adoption
    • En İyi Kullanım: Hızlı ve verimli sıkıştırma
    • Web: https://github.com/facebook/zstd
